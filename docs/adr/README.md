# Architecture Decision Records

ADRs record decisions affecting authoritative ownership, process boundaries, protocols, security, tenant isolation, and release governance that are hard to reverse. Accepted ADRs are not modified except for textual clarification; changing a decision requires a new ADR declaring the supersession relationship.
